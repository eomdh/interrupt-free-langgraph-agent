## 규칙

**고치지 않고 대체한다.** 결정이 바뀌면 기존 문서를 수정하는 게 아니라 새 ADR을 쓰고, 옛 것의 상태를 `대체됨 (→ NNNN)`으로 바꾼다. 틀린 판단을 지우면 **왜 그렇게 생각했었는지**가 사라지는데, 대개 그게 제일 쓸모 있는 기록이다.

**결정만 쓴다.** 사용법·구조 설명은 README, 진행 상황은 `../plan.md`. 여기 있어야 할 건 "왜 이 길을 골랐고 무엇을 감수했나"뿐이다.

**감수하는 것을 반드시 적는다.** 장점만 있는 결정은 결정이 아니라 취향이다. 트레이드오프가 안 써지면 애초에 ADR감이 아니다.

## 형식

맥락 → 결정 → 근거 → 대안 → 결과(얻는 것 / 감수하는 것). 한 장을 넘기지 않는다.
