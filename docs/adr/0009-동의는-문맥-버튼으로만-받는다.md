# ADR 0009 — 동의는 문맥 버튼으로만 받는다

- **상태**: 채택
- **관련**: ADR 0002 · ADR 0008

## 맥락

ADR 0008로 자유 서술 분류가 들어오면서 의도가 들어오는 길이 둘이 됐다. 그런데 **상시 액션 칩이 그대로 남아 있었다.** 입력창과 칩이 같은 자리에서 경쟁하는 구조가 된 것이다.

규칙은 "칩이 이긴다"였다. `classify`는 `client_intent`가 있으면 LLM을 부르지도 않는다. 그래서 이런 일이 벌어진다.

> **[확정]** 칩을 누른 채 *"아니 아직 고칠 게 있어요"* 라고 보낸다
> → `intent=proceed` → `has_draft` 통과 → **`finalize`. 확정된다.**

사용자가 "아니오"라고 썼는데 앱이 확정하고, **아무 안내도 없다.** 동의 게이트라면서 정작 동의를 뒤집는 말을 못 듣는다.

반대 규칙(텍스트가 이긴다)을 골라도 나아지지 않는다. 칩이 장식이 되고, 칩의 값어치였던 결정성과 호출 절약이 사라진다. 충돌을 감지해 되묻는 방법은 왕복만 늘리고 경로가 둘이라는 사실은 그대로다.

**문제는 어느 쪽이 이기느냐가 아니라 두 경로가 공존한다는 것 자체다.**

## 결정

**상시 칩을 없앤다.** 입력은 자유 서술 하나이고, 의도는 분류가 읽는다(ADR 0008).

동의가 필요한 순간에는 **서버가 알려준 문맥 버튼**을 띄운다.

- `ThreadView`에 `actions`를 싣는다. `available_actions()`가 **라우터가 전이를 정할 때 보는 게이트를 그대로 봐서** 유도한다.
- 재료가 모였고 초안이 없으면 `write_now`, 초안이 있으면 `proceed`·`revise`.
- 누르면 버튼 문구가 그대로 사용자 발화가 되어 대화에 남는다.

## 근거

**충돌이 구조적으로 사라진다.** 버튼은 입력창과 경쟁하는 모드 선택이 아니라 **에이전트가 방금 한 제안에 대한 응답**이다. "칩을 눌러 놓고 반대되는 말을 쓰면?" 이라는 상황이 생길 수가 없다.

**제안과 허용이 갈라지지 않는다.** 화면이 스스로 "이제 확정할 수 있겠지"를 판단하면, 서버 게이트와 어긋나는 순간 눌러도 아무 일이 없는 버튼이 생긴다. 그래서 라우터가 쓰는 게이트에서 유도한다 — 새 판단을 만들지 않는다.

**상태에서 유도하므로 새로고침해도 살아난다.** 스트림에서 어느 노드가 돌았는지로 알아내는 방법도 있었지만, 그러면 새로고침하면 버튼이 사라져 ADR 0001의 값을 깎는다. 서버 문구를 문자열로 뒤지는 방법은 프론트를 백엔드 카피에 묶는다.

**되돌리기 비싼 전이에서 결정적 신호가 남는다.** ADR 0008이 감수한 것이 "동의 게이트가 분류 정확도에 묶인다"인데, 생성·확정만큼은 버튼이라는 명시적 행동으로 받는 길이 유지된다.

## 대안

**칩을 두고 충돌만 막는다** — 칩을 누른 채 보낸 텍스트도 분류해서 모순되면 되묻기. 왕복이 늘고 호출도 늘며, 무엇보다 입력 경로가 둘이라는 근본이 그대로다.

**텍스트가 칩을 이기게 한다** — 칩이 장식이 된다. 결정성도 호출 절약도 잃고 발견성만 남는다.

**칩만 없애고 버튼도 안 둔다** — 가장 단순하지만 동의가 전부 분류 정확도에 달리고(ADR 0008의 대가가 최대가 된다), "확정"이라는 동작이 있다는 걸 알 방법이 사라진다.

## 결과

**얻는 것** — 모순되는 입력이 불가능해진다. 무엇을 할 수 있는지는 필요한 순간에 정확히 보이고, 새로고침해도 남는다. 화면은 서버가 허용하는 것만 제안한다.

**감수하는 것** — `provide_info`·`set_questions`는 이제 **분류에만 의존한다.** 칩이라는 우회로가 없어서, 분류가 틀리면 사용자가 바로잡을 방법이 없다. 다만 이 둘은 동의 게이트가 아니라 오분류의 최악이 "되물음 한 번 더"라 받아들일 만하다고 봤다.

`ThreadView`가 커졌다. ADR 0005가 세운 "최소만 내보낸다"는 원칙에 필드를 하나 더한 셈인데, 초안 본문이 아니라 **게이트 상태의 요약**이라 노출 위험은 없다고 판단했다. 다만 여기에 계속 뭔가 얹기 시작하면 그 원칙이 흐려진다.

그리고 **버튼 문구가 고정된 사용자 발화가 된다.** 대화 기록에 *"초안 써주세요"* 가 사용자가 직접 친 말처럼 남는다. 흔적이 남는 편이 낫다고 봤지만, 실제로 사용자가 쓴 말과 버튼이 만든 말이 기록에서 구분되지 않는다.
