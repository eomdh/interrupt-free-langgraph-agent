# 작업 계획

> **이 문서는 버리는 문서다.** 범위와 마일스톤을 잡아두는 용도이고, 구현이 끝나면 README가 대신한다.
> 설계 결정은 여기 쓰지 않는다 — `docs/adr/`에 한 건씩 남긴다. **이 문서와 코드가 어긋나면 코드가 맞다.**

## 무엇을 만드나

대화형 **성과 리뷰 초안 코치**. 평가 기간에 한 일을 인터뷰해서 성과 리뷰(자기평가) 초안을 만들어준다.
LangGraph `StateGraph`로 짜되, **`interrupt()` 없이** 매 POST를 한 번의 실행으로 처리한다.

한 줄 정체: *"`interrupt()` 없이 짠 자율 대화 에이전트 — 매 POST=1턴, 질문은 `AIMessage`로."*

## 왜 이 소재인가

에이전트가 사람에게 **되묻고 기다려야** 하는 구조라서, "사람 입력을 어떻게 기다릴 것인가"가 정면 문제로 드러난다. 그게 이 repo의 헤드라인(ADR 0001)이다. 단발 질의응답 챗봇으로는 그 문제가 안 생긴다.

## 범위 (MVP)

돌아가는 것이 1순위다. 아래가 전부 되면 멈춘다.

- [ ] `StateGraph` — 매 POST = `ainvoke` 1회. 질문은 `AIMessage`로 남기고 END (ADR 0001)
- [ ] `router` 허브 — intent × 상태 게이트로 목적지 노드 결정
- [ ] 동의 게이트 — 초안 생성·확정 둘 다 사용자 승인 뒤에 (ADR 0002)
- [ ] `draft ⇄ tag` self-eval 루프 — 5축 LLM 채점 + 미달 축만 힌트 재주입 + `MAX_REVISE=2` (ADR 0003)
- [ ] 과장·허위 하드 게이트 — 입력에 없는 사실은 무조건 재작성 (ADR 0004)
- [ ] Postgres 체크포인터 — 새로고침하면 문답 전체 복원
- [ ] SSE 노드 진행 스트림 → React 스텝퍼 + 우측 산출물 패널
- [ ] LLM 목 모드 — 키 없이 `docker compose up` 하나로 데모가 돈다

**상태 스케치** (구현하며 바뀔 수 있다 — 확정본은 코드)

```
profile       직무·평가 기간
achievements  성과 목록 (STAR 조각)
draft         성과 리뷰 초안
tags          5축 채점 — 구체성·기여도·문제해결·정량성·과장허위
```

```
onboard → analyze → interview → draft ⇄ tag → finalize
                        ↑___________|
                     (MAX_REVISE=2)
```

## 안 하는 것

repo 관리 규약 §8.2 — *"안 돌아가는 repo는 repo 없는 것보다 나쁘다."* 아래는 시그널을 희석시켜서 뺀다.

- 인증·회원가입 (스레드 ID만으로 충분)
- 배포 인프라 (compose까지만)
- 진짜 토큰 스트리밍 — 노드 단위 progress까지만. 여력 남으면 고도화
- 라우터 intent 임베딩 분류 — few-shot으로 시작
- 체크포인터 마이그레이션 전략

## 마일스톤

각 단계가 **끝날 때마다 돌아가는 상태**를 유지한다. 큰 덩어리 커밋 금지.

| # | 목표 | 완료 기준 |
|---|---|---|
| 1 | 그래프 뼈대 + 실패하는 스펙 | 라우터 전이 테스트가 빨갛게 뜬다 |
| 2 | interrupt-free 1턴 + 체크포인터 | 새로고침해도 문답이 남는다 |
| 3 | 동의 게이트 | 게이트 없이 초안이 생성되지 않는다 |
| 4 | self-eval 루프 | `MAX_REVISE`에서 멈추는 게 테스트로 증명된다 |
| 5 | SSE + 프론트 | 노드 스텝퍼가 실시간으로 움직인다 |
| 6 | 목 모드 + README | 키 없이 클론→실행→데모 |

## 테스트 (원본 0건 → 여기서 정공법)

날카로운 것 몇 개 > 커버리지.

- 라우터: intent × 게이트 조합별 목적지 노드
- 카운터 리셋: `operator.add` reducer가 값을 못 줄이는 함정의 회귀
- 동의 게이트 전이: 승인 없이는 `draft`로 못 간다
- self-eval 루프가 `MAX_REVISE`에서 멈춘다
- fail-safe: 누락·불량 라벨이 전부 미달로 정규화된다
- 과장·허위 게이트: 입력에 없는 고유명사가 통과하지 못한다

LLM은 결정적 스텁으로 목킹, 체크포인터는 `MemorySaver`.
